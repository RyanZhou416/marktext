# Archived Documentation (Electron Era)

This directory contains archived developer documentation from the **Electron era** of MarkText (before the migration to Tauri 2.0).

These documents are preserved for historical reference and may be useful for understanding the original design decisions. They **do not reflect the current architecture**.
